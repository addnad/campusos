## Purpose

This document defines the initial technology choices for building CampusOS.

---

## Core Stack

### Framework

Next.js with TypeScript.

### Database

PostgreSQL.

### ORM

Prisma.

---

## Architecture Philosophy

Technology choices should prioritize:

- Developer speed.
- Maintainability.
- Clear system boundaries.
- Ability to scale.

---

## AI Principle

AI is an intelligence layer that consumes structured academic context.

AI does not own academic data.
